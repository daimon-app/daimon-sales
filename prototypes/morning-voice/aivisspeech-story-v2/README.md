## 共通生成設定

- AivisSpeech Engine 1.0.0、CPU、ローカル生成
- 全文を一つのAudio Queryとして生成
- 句読点・意味の切れ目だけに短い呼吸間を設定
- 文間: 約0.39秒
- 最後の「もう決まってる。」直前: 約0.54秒
- EBU R128 loudnorm: I=-18 LUFS / TP=-1.5 dBTP / LRA=7
- 最大検出音量: 男女とも -1.9 dB（クリッピングなし）
- 形式: MP3 / mono / 44.1kHz / 96kbps CBR
- 生成日時: 2026-08-18 16:33:11 +09:00

初期値の男性0.92・女性0.90では男性42.28秒・女性51.67秒となったため、本文や間を水増しせず、早口感を下げて55〜70秒へ収める目的で上記速度に調整しました。
