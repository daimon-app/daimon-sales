# DAIMON MORNING Edition — CM-B / CM-C 最終絵コンテ

**用途:** `marketing/cm/scripts/cm-master.md`のB/C部分を置換する制作仕様です。対象はMorning専用AABのみです。WORK、NIGHT、切り替えスイッチ、旧PWA、AI生成UI、モックUIは使用禁止です。

> **制作前の前提:** `{{FINAL_AAB_BUILD}}`でMorning専用ホーム→呼吸→固定12枚→最後の一声→戻る、が実機で確認できていること。画面内の文字・音声・所要時間が最終AABと異なる場合は、動画の文言をAABに合わせて修正し、逆に動画に合わせてAABを改変しないこと。

## 共通出力仕様

| 項目 | 仕様 | 受入条件 |
|---|---|---|
| 比率・解像度 | 9:16、1080×1920、H.264 MP4、30fps | エンコード後に1080×1920・30fpsをffprobe等で確認。 |
| 安全領域 | 重要な字幕、商品名、CTAは`x=96–984px / y=260–1460px`に収める | TikTok、Reels、ShortsのUIに重ねても、商品名とCTAが隠れない。 |
| 字幕 | 焼込み。白または金と黒半透明帯で4.5:1以上の視認性を確保 | 無音で意味が通る。自動字幕に依存しない。 |
| 音 | BGMなし。AABの最終音声を使う場合のみ、音量・言語・停止UIを実機と一致 | ミュート視聴で全情報を理解できる。 |
| UI | 収録前に通知、時刻、個人情報、デバッグ表示を除く | Android実機画面であることを示す必要がある場合も、私的情報を露出しない。 |
| 医療・誇大表現 | 禁止 | 診断、治療、睡眠改善、ストレス解消、自己肯定感向上、収入・健康・成功保証を表示しない。 |
| CTA | prelaunchはLP案内のみ、liveはLP経由でPlay案内 | SNS投稿本文のURLも同じUTM registryを使う。動画内に未確定Play URLを焼込まない。 |

## CM-B — 実フロー説明（15秒）

**目的:** 「何をするアプリか」を一度で理解させる。ティザーではなく、Morning専用の実機フローを見せる。  
**投稿用途:** 発売前の主力動画、および発売日に商品理解の固定素材。  
**尺:** 15.0秒。

| 時間 | 実画面 / 映像 | 焼込み字幕（確定文） | 編集・音声指示 |
|---:|---|---|---|
| 0.0–1.0 | 黒地または権利確認済みの無人物背景。アプリ画面はまだ出さない。 | `朝、通知を開く前に。` | 0.2秒フェードイン。BGMなし。 |
| 1.0–3.0 | 最終AABの**Morning専用ホーム**。WORK/NIGHTが一切見えない状態。 | `約90秒の、朝の入口。` | 画面タップで開始する動きを見せる。通知風モックを使わない。 |
| 3.0–5.3 | 最終AABの**呼吸導入**。 | `まず、呼吸する。` | 呼吸リング等の実挙動を等速で見せる。音声が最終AABにある場合も字幕を優先。 |
| 5.3–9.2 | 固定12枚のうち、制作承認済みの代表3枚を実機で順に表示。 | `次に、固定12枚を見る。` | 各画面を少なくとも1.1秒読めるようにする。アファメーション本文を勝手に置換しない。 |
| 9.2–11.4 | 最終AABの**最後の一声**。 | `最後の一声から、現実へ戻る。` | 戻る操作または最後の画面遷移を実挙動で示す。 |
| 11.4–13.0 | 商品名カード。実機画面の静止画を背景にしてもよい。 | `DAIMON MORNING Edition` | 画面中央の安全領域に商品名を固定。 |
| 13.0–15.0 | 商品条件カード。 | prelaunch: `発売日は公式LPで案内`<br>live: `使い方とGoogle Playへの案内は公式LPから` | `490円・買い切り・広告なし`はLP/Playの最終価格と一致する場合だけ表示。未確定時は条件行を出さない。 |

## 収録・承認チェック

| Gate | 受入条件 |
|---|---|
| Screen provenance | すべてのUIカットが`{{FINAL_AAB_BUILD}}`の最終実機キャプチャで、ファイル名・端末・撮影日を台帳に記録。 |
| Morning-only | 映像、音声、字幕、背景、投稿本文の全てにWORK/NIGHT/別商品がない。 |
| Script match | CM-B/Cの全タイムコード、字幕、CTAがこの仕様と一致。変更時は台本・投稿・LPも同時に改版。 |
| Silent comprehension | 音量0で第三者3人が「朝に呼吸と固定12枚を見るAndroidアプリ」と説明できる。 |
| Safe area | 1080×1920の安全領域内に商品名・CTA・重要字幕が入る。TikTok/Reels/Shortsの実機プレビューで確認。 |
| Rights | 背景、実機画面、ロゴ、音声の利用権をasset rights ledgerで`verified`にする。 |
| Release state | prelaunch版ではPlay購入を示さず、live版では有効なLP/Play経路のみを使う。 |
