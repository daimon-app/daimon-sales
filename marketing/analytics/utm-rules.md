# UTMルール

`?utm_source={platform}&utm_medium=organic_social&utm_campaign={prelaunch|launch|evergreen}&utm_content={post_id|profile}`

sourceは `tiktok instagram youtube threads x facebook pinterest linkedin reddit`。正規LP URL確定後に全リンクを生成する。週次はLP流入・Play遷移・購入を主KPIとして上位3本と反応なし3本を比較する。

`utm_content` は投稿30本を `p01`〜`p30`、CMを `cm-a`〜`cm-e`、プロフィールを `profile` とする。媒体が変わってもcontent IDは維持する。
